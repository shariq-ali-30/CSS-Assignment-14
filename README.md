# Facebook Clone

## About The Project

This project is a Facebook-inspired web application built using HTML, CSS, and JavaScript.

The purpose of this assignment was to practice creating a multi-page web application with authentication screens, dashboard layouts, DOM manipulation, responsive design, and interactive user interface components inspired by Facebook. The project also focuses on implementing client-side functionality using JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
- SweetAlert2

## Features

- Facebook-inspired login page design
- User signup page with structured registration form
- Password show/hide toggle functionality
- Client-side login and signup handling using JavaScript
- Interactive dashboard interface after login
- Sidebar navigation with multiple menu options
- News feed style content layout
- Friends, Groups, Events, and other Facebook-inspired sections
- Responsive design for mobile, tablet, and desktop
- Modern UI with icons, images, and hover effects
- Clean multi-page website structure with page navigation
- User-friendly alerts using SweetAlert2

## What I Learned

Through this assignment, I learned:

- How to build a multi-page web application
- How to use JavaScript for DOM manipulation and event handling
- How to create login and signup functionality on the client side
- How to implement password visibility toggle
- How to design a responsive dashboard layout
- How to organize project files into HTML, CSS, JavaScript, and assets
- How to improve user experience with interactive UI components and alerts
